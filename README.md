# 沿海台风信息站

面向沿海居民的台风信息网站规划，帮助用户快速了解：**台风叫什么、在哪里、往哪里去、风力多大，以及所在地发布了什么预警、应该做什么。**

当前阶段：**计划书完成，网站尚未开发，实时数据接口尚未接入。**

## 文档

- [项目计划书](docs/PROJECT_PLAN.md)：产品定位、功能、预警设计、数据方案、技术架构、排期、预算与验收标准。
- [资料来源与接入核查表](docs/SOURCES.md)：已查阅的官方标准，以及开发前需要确认的数据授权和接口条件。

## 首版范围

移动端优先；支持城市/区县选择、多台风切换、中心位置、移动方向与速度、中心风力、历史与预报路径、当地官方分级预警、防御指南、数据时间与异常提示。

默认服务中国大陆沿海居民，建议先选择一个省的 2–3 个沿海城市试点。具体试点城市、数据服务商和预算在开发启动时确定。

## 核心原则

1. 台风中心强度、当地风力与当地官方预警分开显示。
2. 预报路径注明预报时次和不确定性；无授权数据时不虚构实时信息。
3. 官方预警按适用地区、有效状态和发布版本展示；缺失数据不代表无风险。
4. 数据异常保留最近有效信息并标明时间，提供官方信息入口。
