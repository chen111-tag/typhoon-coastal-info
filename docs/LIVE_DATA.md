# 真实数据接入说明

核查日期：2026年9月29日。

## 来源与公开端点

来源为浙江省水利厅的[浙江省台风路径实时发布系统](https://typhoon.slt.zj.gov.cn/)。根据源站自身加载的脚本核查以下公开 JSON 端点，并用源站可见页面交叉核对样本：

- 活跃台风清单：`https://typhoon.slt.zj.gov.cn/Api/TyhoonActivity`（拼写 Tyhoon 为源站原样）。
- 台风详情：`https://typhoon.slt.zj.gov.cn/Api/TyphoonInfo/{tfid}`。

当前端点无需密钥。不使用登录信息，不绕过访问限制。上述端点不是已获得服务承诺的正式开放平台合同；公开可访问不等于获得再分发或商用授权。持续运营前应向数据提供方确认使用、缓存、署名和再分发条件。接口变更或访问限制时，应调整接入或停止采集。

## 字段与含义

| 页面信息 | 来源字段 | 处理 |
| --- | --- | --- |
| 编号、名称 | tfid、name、enname | 保留来源名称与编号 |
| 实况中心 | points 的最新有效 time、lat、lng | 按时刻排序并去重，经纬度校验 |
| 中心风力、风速 | power、speed | 级、米/秒；缺失显示“—” |
| 移动方向、移速 | movedirection、movespeed | 原方向文字、公里/小时；缺失不猜测 |
| 位置和趋势说明 | ckposition、jl | 来源原文，转义后展示 |
| 历史路径 | points | 使用真实观测点 |
| 预报 | 最新观测点下 forecast，tm 等于“中国” | 使用 forecastpoints，保留起报时刻 ybsj；不拼接旧时次 |

活跃清单 time 样本带显式 UTC 偏移；详情 time 样本无时区，按北京时间解释。带偏移的字符串尊重原偏移。内部统一保存 ISO UTC，网页用 Asia/Shanghai 展示。

2026年9月29日核查样本：舒力基（202626），17:00 北京时间，北纬29.2°、东经135.4°，10级、25米/秒，向东北东移动、17公里/小时。该样本仅记录当时接口核验结果，不代表阅读本文时的最新实况。当时中国预报只提供12、24小时，网页不补造48、72小时路径。

## 数据一致性与故障

每次采集先读取清单，再顺序请求各台风详情。请求超时20秒，最多3次；清单最多30个编号，响应大小有限制。校验编号、坐标、时间及合理数值范围；详情落后于清单、同一台风观测倒退或超前异常时拒绝替换有效快照。

`data/typhoons.json` 保存最近成功结果，`data/status.json` 独立保存最近采集状态。失败时从仓库快照和上次已部署快照中保留较新的有效结果；全部不可用时显示数据不可用，不伪装成没有台风。正常返回空清单则显示“当前源清单暂无活跃台风”。

网页每60秒重新读取同源快照；数据采集计划每15分钟运行。网页读取频率不等于官方观测更新频率。同步超过45分钟、观测超过6小时或同步失败均有可见提示。

## 当前不提供的信息

没有接入可验证生命周期的地方官方预警接口。不使用 `warnlevel` 推算城市预警，也不以台风中心风力自动生成预警。城市选择只改变关注位置。

简化示意图不是正式地图服务，没有风圈或概率锥；预报线不表示确定轨迹。不得将本站用作唯一防灾信息渠道。
